# Welcome to Loosh — Subnet 78!

We launched on Bittensor Subnet 78 in February 2026, and we're just getting started.

Loosh is building decentralized inference infrastructure — a network where miners compete to deliver the highest-quality AI responses and validators ensure only the best work earns emissions. Every challenge is scored, every response is evaluated, and the network gets smarter with every block.

## What's Here Now

- **Live Leaderboard** — See which miners are leading in score, stake, and availability, updated in real time
- **Miner & Validator Resources** — Guides, configuration references, and everything you need to get running on the subnet
- **Network Stats** — A growing picture of how the subnet is performing
